## What's Out of Scope ❌

**These BeyondTrust features are intentionally NOT in PRA Sync API:**

- Vault Account Management (separate feature set)
- Jump Approval/Authorization (session workflow, not config)
- Endpoint Automation (separate product)
- Vendor Management (enterprise feature)
- User Provisioning (advanced feature)
- Session Policies (reference data)
- API Account Management (admin-only)

**These are NOT missing bugs - they're design decisions.** PRA Sync API focuses on configuration synchronization only.

## If You Want New Jump Item Types

### Implementation Steps

1. **Copy Protocol Tunnel Jump module**
   ```bash
   cp -r src/jump-item/protocol-tunnel-jump \
        src/jump-item/mysql-tunnel-jump
   ```

2. **Update class names**
   ```
   ProtocolTunnelJump → MysqlTunnelJump
   PROTOCOL_TUNNEL_JUMP → MYSQL_TUNNEL_JUMP
   protocol-tunnel-jump → mysql-tunnel-jump
   ```

3. **Register in modules**
   - Add to `src/jump-item/jump-item.module.ts`
   - Add to discrepancy strategy provider
   - Add configuration variables

4. **Test & deploy**

**Estimated effort**: 1-2 days per type
