## API-SPECIFIC CHANGES

### Pagination Format ✅ Unchanged
- **Per-page parameter**: `per_page` (same)
- **Page parameter**: `current_page` (same)
- **Response headers**: Link header, X-BT-Pagination-* (same)

### Authentication ✅ Unchanged
- **Method**: OAuth 2.0 bearer token
- **Header**: `Authorization: Bearer {token}`
- **Endpoint**: `/oauth2/token` (same)

### Error Codes ✅ Unchanged
Standard HTTP status codes maintained:
- 200: Success
- 201: Created
- 204: No content
- 400: Bad request
- 401: Unauthorized
- 403: Forbidden
- 404: Not found
- 422: Validation error
- 500: Server error

### Rate Limiting ✅ Unchanged
- **Limit**: 20 requests/second, 15,000 requests/hour
- **Headers**: X-RateLimit-* headers included in responses
- **Per-account**: Applied per API account

### Date-Time Format ✅ Unchanged
- **Format**: RFC3339 ISO 8601
- **Timezone**: Always UTC
- **Examples**: 
  - `2025-10-16T14:46:25.930+00:00` ✅
  - `2025-10-16T14:46:25Z` ✅
